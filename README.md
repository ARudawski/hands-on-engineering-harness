# Hands-on Engineering Harness

Practical engineering workflows for Codex and Claude Code, using GitHub for source and pull requests, Linear for work tracking, and stock APM for packaging.

**Status:** planning baseline approved; implementation and compatibility validation are planned. Installation instructions and supported versions will accompany the first release.

## Planned workflows

- Turn a concept into an agreed specification and reviewed Linear tickets.
- Deliver a ticket through small implementation slices, independent reviews and explicit approval gates.
- Keep task records resumable and verification tied to the actual change and commit.

The planned skill set is `plan-feature`, `deliver-ticket`, `clarify-scope`, `write-spec`, `plan-slices`, `implement-slice` and `review-code`, with separate `plan-reviewer` and `code-reviewer` roles.
