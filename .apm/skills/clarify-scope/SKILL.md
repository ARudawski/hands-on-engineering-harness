# Clarify scope

Read applicable guidance, the existing task record and relevant tickets, code/tests and approved specifications. Establish what exists, what is requested and what remains uncertain. An inaccessible source is a gap, not evidence that no related work exists.

Answer repository questions from evidence. Check consequential assumptions with the smallest representative check before dependent work. Ask only remaining material questions, in a short independent round with recommendations and tradeoffs. Wait for answers before dependent decisions.

Agree the outcome, scope, exclusions, constraints and observable acceptance. Preserve accepted limitations unless new evidence changes their consequences. Record influential sources and decisions in the existing `.tmp/<task>/spec.md`; keep its index brief.

Report settled decisions and remaining blockers. Do not change implementation or publish external resources. If used within another workflow, return to that workflow's approval gate.
